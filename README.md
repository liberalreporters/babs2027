# Babatunde Ogunlade — Global Responsive Website
Premium static multi-page public-information website.

## Global architecture
- Shared global CSS: `assets/css/style.css`
- Shared global JS: `assets/js/main.js`
- Consistent header, navigation, footer, breadcrumbs and responsive components
- Mobile navigation with ARIA state and keyboard support
- Active-page navigation state
- Skip link and reduced-motion support
- Page metadata, canonical URLs, Open Graph, sitemap and robots
- Vercel `404.html` and `vercel.json`
- No paid libraries or external runtime dependencies

Upload the **contents** of this package to the GitHub repository configured for the Vercel project.
